## 📌 บทสรุปโครงการ (Executive Summary)
ระบบบริหารจัดการสัญญาเช่าอสังหาริมทรัพย์และเงินประกันแบบกระจายศูนย์ พัฒนาขึ้นบน Ethereum Blockchain (Sepolia Testnet) เพื่อแก้ไขปัญหาความไม่โปร่งใสในการจัดเก็บเงินประกัน ข้อขัดแย้งในการตรวจสภาพห้อง และการคืนเงินประกันเมื่อสิ้นสุดสัญญาเช่า

---

## ⚙️ คุณสมบัติระบบตามข้อกำหนด (Functional Requirements Checklist)

| ข้อที่ | ฟังก์ชันที่ต้องการ | คำอธิบายการทำงานใน Smart Contract & DApp | สถานะ |
| :---: | :--- | :--- | :---: |
| **1** | **ลงทะเบียนทรัพย์สิน (Register Property)** | เจ้าของห้องสามารถลงทะเบียนห้องพัก ระบุชื่อห้อง สถานที่ ค่าเช่าต่องวด (ETH) และเงินประกันสัญญา (ETH) | ✅ เสร็จสมบูรณ์ |
| **2** | **สร้างสัญญาเช่า (Create Rental Agreement)** | เจ้าของห้องเลือกห้องว่าง กำหนดกระเป๋าผู้เช่า วันเริ่มต้น-สิ้นสุด และเงื่อนไขสัญญา (Terms) | ✅ เสร็จสมบูรณ์ |
| **3** | **ยืนยันสัญญา (Confirm Agreement)** | ผู้เช่าและเจ้าของห้องยืนยันการยอมรับเงื่อนไขสัญญาด้วย Wallet ของตนเองบน Blockchain | ✅ เสร็จสมบูรณ์ |
| **4** | **ฝากเงินประกัน (Deposit Security)** | ผู้เช่าโอนเงินประกันในรูปแบบ ETH เข้าสู่ Smart Contract เพื่อล็อกห้องและเริ่มสัญญา (Active) | ✅ เสร็จสมบูรณ์ |
| **5** | **บันทึกค่าเช่า (Record Rental Payment)** | ผู้เช่าโอนค่าเช่ารายงวดผ่าน DApp เงินถูกส่งตรงเข้ากระเป๋าเจ้าของห้องทันที พร้อมบันทึกประวัติงวดและเวลา | ✅ เสร็จสมบูรณ์ |
| **6** | **คืนเงินประกัน (Refund Deposit)** | เมื่อสิ้นสุดสัญญา เจ้าของตรวจห้อง: หากไม่มีความเสียหายระบบคืนเงินประกัน 100% ให้ผู้เช่าทันที หรือยื่นยอดหักพร้อมเหตุผล | ✅ เสร็จสมบูรณ์ |
| **7** | **จัดการข้อโต้แย้ง (Rental Dispute)** | หากผู้เช่าคัดค้านยอดหักเงิน สัญญาจะเข้าสู่สถานะ Disputed ให้ผู้มีอำนาจ (SmartLiving Arbitrator) วินิจฉัยและปล่อยเงิน | ✅ เสร็จสมบูรณ์ |

**กฎทางธุรกิจสำคัญ (Key Business Rules):**
1. การหักเงินประกันต้องระบุเหตุผลและหลักฐานเสมอ
2. การคืนเงิน/หักเงินประกันต้องไม่เกินยอดเงินประกันคงเหลือจริงใน Smart Contract (`TOTAL_MUST_EQUAL_DEPOSIT_BALANCE`)

## 🚀 สถาปัตยกรรมและเทคโนโลยีที่ใช้
* **Smart Contract:** Solidity `^0.8.20` (`SmartPropertyRental.sol`)
* **Frontend:** Single-Page Application (HTML5, Modern CSS, Vanilla JavaScript)
* **Web3 Integration:** `Web3.js v1.10.0`
* **Network Mode (Hybrid):**
  * **โหมดที่ 1: Infura HttpProvider + Private Key** (ลงนามธุรกรรมแบบ Local Signing ภายในเบราว์เซอร์ พร้อมระบบ Retry ป้องกัน Rate Limit `-32005` และปุ่มสลับ Sepolia Public Node)
  * **โหมดที่ 2: MetaMask Browser Extension** (เชื่อมต่อผ่าน `window.ethereum` เพียงคลิกเดียว)

## 🛠️ ขั้นตอนการ Deploy Smart Contract บน Remix IDE

1. เปิดเว็บไซต์ [Remix Ethereum IDE](https://remix.ethereum.org/)
2. ในโฟลเดอร์ `contracts/` สร้างไฟล์ใหม่ชื่อ `SmartPropertyRental.sol`
3. คัดลอกโค้ดจากไฟล์ [SmartPropertyRental.sol](SmartPropertyRental.sol) ไปวางใน Remix
4. ไปที่แท็บ **Solidity Compiler**:
   * Compiler Version: `0.8.20` หรือใหม่กว่า
   * คลิก **Compile SmartPropertyRental.sol**
5. ไปที่แท็บ **Deploy & Run Transactions**:
   * Environment: เลือก **Injected Provider - MetaMask**
   * ตรวจสอบว่า MetaMask เชื่อมต่อกับเครือข่าย **Sepolia Testnet**
   * Contract: เลือก `SmartPropertyRental`
   * คลิก **Deploy** แล้วกดยืนยันใน MetaMask
6. เมื่อ Deploy สำเร็จ ให้คัดลอก **Contract Address** (เช่น `0x...`) มาวางในช่อง Contract Address บนหน้าเว็บ DApp หรือใส่ในไฟล์ `index.html` ที่ตัวแปร `DEFAULT_CONTRACT_ADDRESS`

## 🧪 คู่มือการทดสอบระบบอย่างละเอียด (Step-by-Step Test Guide)

### ขั้นตอนที่ 1: ตั้งค่าการเชื่อมต่อ (Section 0)
1. เปิดหน้าเว็บ `index.html`
2. วาง **Contract Address** ที่ได้จาก Remix
3. เลือกวิธีการเชื่อมต่อ:
   * **วิธีที่ A (MetaMask):** คลิกปุ่ม **"🦊 เชื่อมต่อ MetaMask"**
   * **วิธีที่ B (Infura):** กรอก **Private Key** ของกระเป๋า แล้วคลิก **"🔗 เชื่อมต่อผ่าน Infura"**
   *(สามารถคลิกปุ่ม "⚡ สลับใช้ Public Node" หากติดโควต้าคำขอ)*
4. คลิกปุ่ม **"⚡ เติมข้อมูลทดสอบ"** เพื่อกรอกตัวอย่างห้องเช่าให้อัตโนมัติ

---

### ขั้นตอนที่ 2: ลงทะเบียนห้องพัก (แท็บ "🏢 1. เจ้าของห้อง")
1. ในการ์ด **"1. ลงทะเบียนทรัพย์สิน"**:
   * ใส่ชื่อห้อง เช่น `Deluxe 402 — SmartLiving Tower`
   * ค่าเช่าต่องวด เช่น `0.0001 ETH`
   * เงินประกันสัญญา เช่น `0.0002 ETH`
2. คลิก **"➕ ลงทะเบียนห้องเช่าใหม่"** และยืนยันธุรกรรม
3. ห้องพักจะปรากฏในระบบและพร้อมให้เช่า

---

### ขั้นตอนที่ 3: สร้างสัญญาเช่า (แท็บ "🏢 1. เจ้าของห้อง")
1. ในการ์ด **"2. สร้างสัญญาเช่า"**:
   * เลือกห้องเช่าที่เพิ่งลงทะเบียน
   * ระบุกระเป๋าผู้เช่า (สามารถกดปุ่ม *"ใช้กระเป๋าปัจจุบัน"* หรือใส่กระเป๋าที่ 2)
   * กำหนดระยะเวลาและเงื่อนไข
2. คลิก **"📝 สร้างสัญญาเช่าและยืนยันฝ่ายเจ้าของ"**

---

### ขั้นตอนที่ 4: ยืนยันสัญญาและวางเงินประกัน (แท็บ "👤 2. ผู้เช่า")
1. สลับไปแท็บ **"👤 2. ผู้เช่า"**
2. เลือกสัญญาเช่าที่เพิ่งสร้าง
3. คลิกปุ่ม **"✍️ 3. กดยืนยันสัญญา (Wallet)"** เพื่อยืนยันเงื่อนไข
4. เมื่อสถานะเปลี่ยนเป็นรอวางเงินประกัน ให้คลิกปุ่ม **"💰 4. วางเงินประกันเข้า Contract"** (โอนเงิน `0.0002 ETH` เข้า Smart Contract)
5. สัญญาจะเปลี่ยนสถานะเป็น **Active** (ห้องพักถูกล็อกไม่ให้คนอื่นเช่าซ้ำ)

---

### ขั้นตอนที่ 5: ชำระค่าเช่ารายงวด (แท็บ "👤 2. ผู้เช่า")
1. ในการ์ด **"5. ชำระค่าเช่ารายงวด"**:
   * เลือกสัญญาเช่าที่ Active
2. คลิกปุ่ม **"💸 โอนชำระค่าเช่าเข้าเจ้าของห้องทันที"**
3. เงินค่าเช่าจะถูกส่งตรงเข้ากระเป๋าของเจ้าของห้องทันที และบันทึกประวัติงวดลงใน Blockchain
4. สามารถไปดูประวัติในแท็บ **"📋 4. สำรวจห้องเช่า & ประวัติธุรกรรม"**

---

### ขั้นตอนที่ 6: ตรวจสภาพห้อง & ขอหักเงินประกัน (แท็บ "🏢 1. เจ้าของห้อง")
1. สลับกลับมาแท็บ **"🏢 1. เจ้าของห้อง"**
2. เลื่อนลงมาที่การ์ด **"6. ตรวจสภาพห้อง & จัดการเงินประกัน"**
3. เลือกสัญญาเช่า
4. **กรณีที่ 1 (คืนเงินเต็ม):** ใส่ยอดหัก `0 ETH` แล้วกดส่งผลตรวจ -> เงินประกัน `0.0002 ETH` จะโอนคืนผู้เช่าทันที สัญญาสิ้นสุดอย่างสมบูรณ์
5. **กรณีที่ 2 (มีความเสียหาย):** ใส่ยอดหัก เช่น `0.0001 ETH`, เหตุผล เช่น `ผนังเป็นรอยลึก`, ลิงก์หลักฐาน แล้วกดส่งผลตรวจ -> สัญญาจะเข้าสู่สถานะ `InspectionPending`

---

### ขั้นตอนที่ 7: การตอบรับและการจัดการข้อพิพาท (แท็บ "👤 ผู้เช่า" & "⚖️ คนกลาง")
1. **ฝั่งผู้เช่า (แท็บ "👤 2. ผู้เช่า"):**
   * หากยอมรับ: กด **"✅ ยอมรับยอดหักเงิน"** -> ระบบจะโอนเงินหักให้เจ้าของ และเงินประกันส่วนที่เหลือคืนให้ผู้เช่าทันที
   * หากคัดค้าน: ระบุเหตุผลคัดค้าน แล้วกด **"⚠️ คัดค้าน/ส่งข้อพิพาทให้คนกลางตัดสิน (Dispute)"** -> สัญญาจะเปลี่ยนเป็น `Disputed`
2. **ฝั่งคนกลาง (แท็บ "⚖️ 3. คนกลาง / ข้อพิพาท"):**
   * เลือกสัญญาที่มีข้อพิพาท
   * ตรวจสอบหลักฐานและข้อโต้แย้งจากทั้ง 2 ฝ่าย
   * ระบุจำนวนเงินที่จะจ่ายให้เจ้าของ และเงินที่จะคืนผู้เช่า (ยอดรวมต้องเท่ากับเงินประกันคงค้างพอดี)
   * บันทึกคำวินิจฉัย แล้วกด **"⚖️ บันทึกคำตัดสินและปล่อยเงินประกัน"**
   * Smart Contract จะปล่อยเงินตามคำตัดสิน และสิ้นสุดสัญญาอย่างโปร่งใส ตรวจสอบย้อนหลังได้ 100%
